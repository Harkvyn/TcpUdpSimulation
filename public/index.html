⚙ Pengaturan

TCP
  • Koneksi 3-way handshake
  • Data dipecah jadi segmen ≤ MSS (1460B)
  • Setiap segmen dapat ACK
  • Retransmit jika timeout
UDP
  • Connectionless, header 8 byte
  • Data > MTU → IP-layer buat fragmen
  • Tidak ada ACK otomatis
  • Fragmen hilang → seluruh datagram rusak
